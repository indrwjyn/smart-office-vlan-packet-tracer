# Konfigurasi per Device

File di folder ini disusun ulang dari perintah CLI dan hasil `show running-config` proyek.
Sebelum dipakai sebagai acuan resmi, bandingkan dengan `show running-config` terbaru di Packet Tracer.

Access Point tidak punya file config teks. Pengaturannya: SSID `SmartOffice-Guest`, WPA2-PSK, enkripsi AES, Port 0 speed dan duplex Auto.
Passphrase sengaja tidak dicantumkan.
